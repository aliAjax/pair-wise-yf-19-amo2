# 标本馆拍照排期台

替代白板排期的数字化拍照作业台：预置柜位与标本，按柜位时段安排取件、拍摄、归柜，数据保存在浏览器本地，重开页面继续作业。

## 功能与规则

- 每项排期写明**柜位、优先级（普通/加急）、预计时长**。
- **同一柜位同一时段只能排一项**；普通任务自动排入该柜位最早空档。
- **加急插入**：指定插入时段；撞上拍摄中任务或其他加急任务时拒绝插入；同柜位后续普通任务自动级联顺延，列表与详情标注新旧时段。
- 状态流转：
  - 已排期 →（取件）**拍摄中** →（核验通过）**已归柜**
  - 拍摄中 →（照片缺失 / 标签不清）**需补拍** → 原柜位重新排入
- **取件后、归柜前同一标本不能再次排期**；退回补拍时**原柜位保留**，补拍重排仍落在该柜位。
- 排期列表、柜位时间轴、详情抽屉共用同一份本地数据（localStorage），页面右上角可重置回预置数据。

## 分层结构

排期规则、数据存取、页面展示三层分开承接：

```
src/
├── types.ts                 # 领域模型（柜位 / 标本 / 任务 / 状态）
├── rules/scheduler.ts       # 排期规则：纯函数，不依赖 React 与存储
├── data/
│   ├── seed.ts              # 预置柜位与标本（含当日初始排期）
│   └── storage.ts           # localStorage 读取 / 校验 / 写入
├── state/
│   ├── store.ts             # 承接规则操作并写回本地
│   └── selectors.ts         # 列表 / 时间轴 / 详情共用派生数据
└── components/              # 页面展示：表单、时间轴、列表、详情
```

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev        # 开发，端口 62007
npm run build      # 类型检查与生产构建（先执行 tsc --noEmit）
npm run check:rules  # 运行排期规则测试（33 项断言）
```
