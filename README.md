# 植物标本馆 · 拍照排期台

数字化拍照替代白板排班：统一管理取件、拍摄、归柜的柜位时段，避免撞车。

## 功能

- 预置 6 个柜位、10 份标本，开箱即有当日档期（含拍摄中、待取件、退回补拍、已归柜等状态）
- 每条排期写明 **柜位 / 优先级 / 预计时长 / 具体时段**，同一柜位同一时段只排一项
- **加急插入**：排到同柜所有普通任务之前，后续普通任务自动顺延，列表与时间轴显示新时段与“由 HH:MM 顺延”标记
- 流程流转：待取件 → 取件（柜位锁定）→ 拍摄中 → 质检归柜（柜位释放，后续任务自动前移）
- **退回补拍**：照片缺失或标签不清一键退回，原柜位保留并回到该柜队列最前
- 排期列表、柜位时间轴、详情面板共用同一份数据；数据存 localStorage，重开页面继续
- 18:00 后溢出提示、状态筛选、流转日志、恢复预置数据

## 分层结构

- `src/domain/`：排期规则层（类型、预置数据、排期/顺延/退回算法），不依赖 React 与存储
- `src/store/storage.ts`：数据存取层（localStorage 读写、版本兜底、重置）
- `src/components/`：页面展示层（列表、时间轴、详情操作、表单）
